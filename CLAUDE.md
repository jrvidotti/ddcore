# ddcore

**ddcore** (*Data Driven Core*) — a Go + TypeScript + Postgres framework in the spirit of Frappe.
Read `docs/agent/index.md` (the API reference for writing apps), `DEVELOPMENT.md` (how work is
done here) and `docs/plan-v1.md` (the design; in Portuguese, historical). `apps/demo` is the
example app this checkout's `ddcore.json` loads; product apps live in their own repositories.

- `make build` compiles the desk and the binary; `./bin/ddcore dev` serves :8090 with hot reload; `make test` runs Go + TS.
- Dev Postgres: the `ddcore-pg` container on port 5455 via `make docker-up` (Docker Compose). The Go tests use the `ddcore_test` database (recreated).
- App code is **synchronous** TypeScript running in goja (no `await` on the server). Screen scripts use `@ddcore/desk-sdk`.
- `.ddcore/types.d.ts` is generated (`ddcore types`) — do not edit it.
- **English is the source language.** Every string a person reads — a `_()`/`__()` call, a `label:`, a Select's values — is written in English and is a catalogue key; translations live in `translations/<lang>.csv`, generated by `ddcore i18n extract`. `make check` fails on a key with no translation. The contract is `docs/agent/i18n.md`.
- MCP: `.mcp.json` points at `./bin/ddcore mcp`; use the tools rather than touching the database by hand.
